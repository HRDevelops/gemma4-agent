Problem

Fix real GitHub issues with a small open model on fixed compute

The agent reads an issue, explores the repository with shell and file tools, edits code and submits a patch. Hidden unit tests decide whether the issue is solved.

Published SWE agents use frontier models, unlimited compute and tests to pick patches. Here there is none of that: only the agent's configuration can change.

Model

Gemma 4 31B and E4B, 4-bit QAT

Compute

4 × L4 GPUs, 12 h for about 120 hidden issues

We control

Prompt, tools, sampling, limits, LoRA adapter

Score

Share of issues resolved; public split ≈ 58 tasks

Kaggle Gemma 4 Developer Agent competition
The task: given a real GitHub issue and a repository snapshot, the agent explores and edits with tools, then submits a patch, and hidden tests decide. The competition fixes the model to Gemma 4, the hardware to four L4 GPUs, and the time to twelve hours for about 120 hidden issues. We can only change the configuration. That is a realistic small-model setting, very different from most published SWE-agent work.
