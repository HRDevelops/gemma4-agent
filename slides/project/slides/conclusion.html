Conclusion

Conclusions and limitations

  1. From the Budget-Fit baseline to Patchsmith-check: +4.0 local tasks, 71% fewer wasted runs, 0.13 → 0.20 on Kaggle.
  2. Count measured cost, not nominal limits; spend it on budget per run, not on samples.
  3. Use several seeds, paired tests and a screen → confirm protocol.
  4. Derive agent changes from within-task contrasts of solved and failed traces.

Limitations

One model family; four repositories, 89% fastapi and rich; holdouts over seeds and solvable tasks; H100 instead of L4; +0.8 on fresh seeds alone is not significant.
